# Правила Агента San Porfume

Перед ответом на вопросы, изменением спецификаций или правкой кода в этом проекте используй локальный навык:

`$san-porfume-spec-router`

## Главное Правило

Сайт San Porfume должен быть на русском языке.

Все тексты для клиента, подписи в админке, кнопки, сообщения, ошибки, пустые состояния и тексты сценариев должны быть написаны на русском, если пользователь явно не попросил другой язык.

Главная спецификация проекта: `Spec/Functional Map.md`, потому что в ней собрана почти вся информация о сайте.

## Куда Смотреть

- Главная спецификация проекта: `Spec/Functional Map.md`
- Спецификации функций: `Spec/feature-specs/`
- Истории пользователя: `Spec/user-stories/истории-пользователя.md`
- Технические спецификации: `Spec/технические/`
- Общий контекст продукта: `Spec/Global spec.md`

Сначала проверяй `Spec/Functional Map.md`, затем самую конкретную спецификацию функции, затем истории пользователя, затем технические спецификации. `Spec/Global spec.md` используй только как общий контекст продукта.

## Планы Разработки

Планы разработки хранятся в папке `План-разработки/`.

- Активные планы: `План-разработки/Активные-планы/`
- Завершенные планы: `План-разработки/Завершенные-планы/`

Когда пользователь просит составить план разработки, создай отдельный `.md` файл в папке `План-разработки/Активные-планы/`.

Название файла должно быть понятным по задаче. Лучше использовать формат:

`ГГГГ-ММ-ДД-краткое-название-плана.md`

План должен быть написан на русском языке и должен ссылаться на нужные спецификации, особенно на `Spec/Functional Map.md`.

Во время работы по плану обновляй статусы задач внутри файла, чтобы было видно, что уже сделано, что в работе, а что осталось.

Когда работа по плану завершена, перемести файл из `План-разработки/Активные-планы/` в `План-разработки/Завершенные-планы/`, чтобы сохранить историю выполненных планов.

Не удаляй завершенные планы без прямой команды пользователя.
