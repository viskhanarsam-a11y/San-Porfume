# Feature Spec: Заказ Через WhatsApp И Telegram

## Цель

Пользователь должен быстро перейти из выбранного аромата в диалог с продавцом.

## Что Видит Пользователь

- кнопку WhatsApp;
- кнопку Telegram;
- контактный номер продавца: `+79287352134`.

## Поведение

При нажатии на WhatsApp или Telegram сайт открывает выбранный канал связи.

Если пользователь нажал кнопку из карточки конкретного аромата, в сообщение желательно подставить название товара.

Рекомендуемый текст:

`Здравствуйте! Хочу узнать про парфюм [название парфюма].`

Покупка не оформляется на сайте. На сайте нет корзины, онлайн-оплаты и формы заказа. Все детали покупки обсуждаются напрямую с продавцом.

## Данные

- номер продавца;
- ссылка WhatsApp;
- ссылка Telegram;
- название выбранного аромата.

## Исключительные Ситуации

Если WhatsApp или Telegram не открылись, показывается:

`Не удалось открыть связь с продавцом. Напишите напрямую на номер +79287352134.`

Если связь открывается не из конкретного товара, можно использовать общий текст:

`Здравствуйте! Хочу уточнить наличие парфюмов San Porfume.`
