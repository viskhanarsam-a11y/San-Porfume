# Feature Spec: Админ Ассортимент

## Цель

Админ должен управлять товарами, чтобы ассортимент, цены и наличие на сайте оставались актуальными.

## Что Может Делать Админ

- добавить новый парфюм;
- изменить название;
- изменить фото;
- изменить цену;
- изменить объем;
- изменить описание аромата;
- изменить основные аккорды;
- изменить наличие;
- скрыть товар с сайта;
- удалить товар.

## Поведение

После сохранения изменения должны отображаться на пользовательской части сайта.

Если админ скрывает товар, он пропадает из каталога.

Если админ меняет наличие, новый статус отображается в каталоге и карточке аромата.

Первая версия админки должна быть простой. Роли, отчеты, аналитика и сложные права доступа не нужны.

## Данные

Обязательные поля товара:

- id;
- название;
- фото;
- объем;
- цена;
- наличие;
- описание;
- основные аккорды;
- статус отображения на сайте.

Дополнительные поля:

- бренд;
- пол;
- концентрация.

## Исключительные Ситуации

Если админ пытается сохранить товар без обязательных данных, система должна подсказать, какие поля нужно заполнить.

Если фото не загружено, товар можно сохранить с заглушкой, если остальные обязательные данные заполнены.

Если изменения сохранились, но не появились на сайте, это считается ошибкой обновления данных.
