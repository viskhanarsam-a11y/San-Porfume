# Feature Spec: Каталог

## Цель

Пользователь должен увидеть все ароматы San Porfume на главной странице без регистрации, фильтров, корзины и лишних шагов.

## Что Видит Пользователь

Каталог отображается как список карточек ароматов. В каждой карточке есть:

- фото;
- название;
- объем;
- цена;
- наличие;
- действие для открытия подробностей.

Для первой версии основной объем товара - 125 мл.

## Поведение

Пользователь листает страницу вниз и видит товары. Отдельный большой каталог с фильтрами в первую версию не входит.

Если товар скрыт админом, пользователь не видит его в каталоге.

Если товар не в наличии, он может оставаться в каталоге, но статус должен быть понятным.

## Данные

- id;
- название;
- фото;
- объем;
- цена;
- наличие;
- статус отображения на сайте.

## Исключительные Ситуации

Если товаров нет, показывается текст:

`Сейчас ассортимент обновляется. Напишите нам в WhatsApp или Telegram, чтобы уточнить наличие.`

Если у товара нет фото, показывается аккуратная заглушка.
