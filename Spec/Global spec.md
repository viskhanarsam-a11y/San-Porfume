# Global Spec: San Porfume

## 1. Кто?

San Porfume - личный проект по продаже оригинальных парфюмов.

Проект создается для клиентов, которые хотят купить качественные и оригинальные духи без лишней сложности. Клиенту важно быстро увидеть ассортимент, понять, какие ароматы есть в наличии, и связаться для покупки.

Основная аудитория:

- люди, которые ищут оригинальный парфюм для себя;
- покупатели, выбирающие подарок;
- постоянные клиенты, которым удобно смотреть ассортимент онлайн;
- клиенты, которым важны доверие, качество и понятная связь с продавцом.

## 2. Где?

Сайт будет работать как онлайн-витрина San Porfume. Клиенты смогут открыть сайт с телефона или компьютера и посмотреть ассортимент в одном месте.

Главный сценарий использования:

- клиент заходит на сайт;
- смотрит доступные парфюмы;
- выбирает интересующий аромат;
- связывается с продавцом через удобный канал связи.

Сайт должен быть особенно удобным для мобильных устройств, потому что большинство клиентов будут заходить с телефона.

## 3. Зачем?

Сайт нужен, чтобы собрать весь ассортимент San Porfume в одном удобном месте и упростить выбор парфюма для клиента.

Главные цели проекта:

- показать, что San Porfume продает оригинальные духи;
- дать клиенту быстрый доступ к ассортименту;
- сделать выбор аромата удобным и понятным;
- повысить доверие к продавцу;
- упростить обращение для покупки;
- создать аккуратное и премиальное впечатление о бренде.

San Porfume должен восприниматься как надежный личный магазин оригинальной парфюмерии.

## 4. Общее Понимание Проекта

San Porfume - это не большой маркетплейс, а личная онлайн-витрина с выбранными ароматами.

Проект должен быть:

- простым для клиента;
- красивым и аккуратным;
- удобным на телефоне;
- ориентированным на доверие;
- сфокусированным на оригинальных парфюмах.

Подробные функции, страницы, каталог, фильтры, карточки товаров и технические решения будут описаны в отдельных спецификациях.
