# План Разработки: Организация Планов Разработки

## Статус

Активный

## Цель

Организовать понятный процесс хранения планов разработки, чтобы каждый план сначала находился в активной папке, а после завершения переносился в историю завершенных планов.

## Главные Спецификации

- `AGENTS.md`
- `Spec/Functional Map.md`

## Задачи

- [x] Создать папку `План-разработки/`.
- [x] Создать папку `План-разработки/Активные-планы/`.
- [x] Создать папку `План-разработки/Завершенные-планы/`.
- [x] Добавить `.gitkeep`, чтобы пустые папки сохранялись в проекте.
- [x] Описать процесс работы с планами в `AGENTS.md`.
- [ ] Использовать эту структуру для следующих планов разработки.
- [ ] После полной проверки процесса перенести этот план в `План-разработки/Завершенные-планы/`.

## Правила Работы С Планами

1. Когда пользователь просит составить план разработки, создать отдельный `.md` файл в `План-разработки/Активные-планы/`.
2. Писать план на русском языке.
3. Сначала сверяться с `Spec/Functional Map.md`, потому что это главная спецификация проекта.
4. Во время разработки обновлять статусы задач внутри активного плана.
5. После завершения работы перенести файл плана в `План-разработки/Завершенные-планы/`.
6. Завершенные планы не удалять без прямой команды пользователя.

## Примечание

Этот план создан как первый активный план, чтобы зафиксировать уже организованный механизм работы с планами разработки.
