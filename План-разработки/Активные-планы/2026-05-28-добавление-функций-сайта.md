## Обязательные Функции Первой Версии

- [ ] Главный экран San Porfume с короткой информацией о магазине.
- [ ] Акцент на оригинальные парфюмы.
- [ ] Кнопка `Смотреть ассортимент`, которая ведет к товарам.
- [ ] Отображение ароматов на главной странице без отдельного большого каталога.
- [ ] Карточки ароматов с фото, названием, объемом 125 мл, ценой и наличием.
- [ ] Открытие подробной информации об аромате.
- [ ] Подробная карточка аромата с описанием и основными аккордами.
- [ ] Кнопка WhatsApp для связи с продавцом.
- [ ] Кнопка Telegram для связи с продавцом, если будет указана ссылка или имя пользователя Telegram.
- [ ] Передача названия выбранного аромата в сообщение продавцу.
- [ ] Показ контактного номера продавца: `+79287352134`.
- [ ] Статус товара `В наличии`.
- [ ] Статус товара `Нет в наличии`.
- [ ] Возможность написать продавцу даже по товару, которого нет в наличии.
- [ ] Пустое состояние, если на сайте пока нет видимых ароматов.
- [ ] Заглушка, если у товара нет фото.
- [ ] Сообщение при плохом интернете.
- [ ] Сообщение, если информация об аромате не загрузилась.
- [ ] Сообщение, если кнопка связи не открылась.
- [ ] Удобная мобильная версия.

## Технические Решения, Которые Нужно Закрыть Перед Кодом

- [ ] Выбрать технологический стек.
- [ ] Решить, нужен ли отдельный backend.
- [ ] Решить, где будет база данных.
- [ ] Решить, где будут храниться фото товаров.
- [ ] Решить, где будет хостинг.
- [ ] Указать имя пользователя Telegram или прямую ссылку.
- [ ] Решить, показывать ли кнопку Telegram, если ссылка еще не настроена.
- [ ] Зафиксировать правила загрузки фото: форматы, размер, хранение.
- [ ] Зафиксировать формат карточки аромата: модальное окно или отдельная страница.
- [ ] Зафиксировать правила валидации товара в админке.
- [ ] Централизовать повторяющиеся тексты: название, телефон, ошибки, сообщения.

## Не Входит В Первую Версию

Эти функции не добавлять без отдельной команды пользователя:

- регистрация пользователя;
- вход клиента в аккаунт;
- личный кабинет;
- большой каталог с фильтрами;
- корзина;
- онлайн-оплата;
- оформление заказа на сайте;
- уведомления о появлении товара;
- сложная панель пользователя;
- аналитика и отчеты в админке;
- роли администраторов;
- мультиязычность.
